# Security Policy

## Supported Versions

This repository is a portfolio and demonstration project. Security fixes are applied to the latest version on the `main` branch only.

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Please use GitHub's private vulnerability reporting feature:
1. Go to the **Security** tab of this repository
2. Click **Report a vulnerability**
3. Provide a description of the issue and steps to reproduce

Alternatively, you can contact the maintainer directly via the contact details on their GitHub profile.

I will acknowledge your report within 48 hours and aim to provide a fix or mitigation within a reasonable timeframe.

## Scope

This is a portfolio/demonstration project. While I take security seriously, please note:
- This project may use mock or sample data
- It is not intended for production use without further hardening
- Dependencies should be kept up to date via Dependabot alerts
